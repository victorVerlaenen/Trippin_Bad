# Trippin Bad
### Game jam I made togheter with Raven Eriksson as the artist
![alt text](./Assets/Art/World/StartScreen/StartScreen_1.png)
This is a small unity project where you have to reach the top by jumping on platforms and skulls. 
The skulls have a color corresponding to xbox controller buttons, and you have to click the correct button to jump on the skull.
